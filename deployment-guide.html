Architecture Implementation Deployment guide

Deploy the homelab

A human-readable trace of the current repository: run the public Task command, understand its result, then follow the links to the code that performs it. Work from the repository root on the trusted administrator Mac. Rows are in execution order; conditional rows are labelled.

Before starting: prepare the ignored .envrc using .envrc.example, load it with direnv, and keep secrets out of Git and terminal transcripts. Review design constraints and current progress before a fresh rebuild. This guide describes commands; it does not run them.

Safety boundary: the first ZFS pool creation erases one specified physical disk; VM ID 9000 is the Packer template; test VM ID 9900 is disposable. Never run the guarded first-time or apply steps without checking their targets and reviewing the plan. No routine Task command destroys persistent application data.
